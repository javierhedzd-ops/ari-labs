    Para programar

    Lo que más aparece en las guías de 2026. Un plugin agrega habilidades a Claude Code. Las primeras tres son las que conviene instalar primero.

    Cómo se instalan

    Dentro de Claude Code escribe /plugin, entra a Discover y elige. O por comandos, como este ejemplo con Caveman:

    claude plugin marketplace add JuliusBrussee/caveman
claude plugin install caveman@caveman

    Después, cierra Claude Code y ábrelo de nuevo.

    No hay herramientas con eso. Prueba otra palabra.

    Para trading

    Son proyectos de la comunidad, no oficiales. No se revisó su código ni si siguen mantenidos: míralos en GitHub antes de instalar. La más ligera para empezar es tradingview-mcp.

    Antes de nada: un backtest dice cómo le habría ido a una estrategia en el pasado, no cómo le irá en el futuro. Claude no es asesor financiero. Empieza siempre con cuenta demo.

    OmniRoute en la computadora

    Un programa que corre en tu computadora y junta muchos modelos de IA, gratis o de paga, detrás de una sola dirección local. Claude Code se conecta a ella; si un modelo se agota, pasa al siguiente.

    Ten claro esto: los modelos que contesten serán los de los proveedores que conectes (Groq, NVIDIA, Gemini y otros), no necesariamente Claude. Sirve para aprender y para trabajo ligero; la calidad y el límite diario dependen de cada proveedor.

    Instalación paso a paso

    Los comandos son los mismos en Windows, Mac y Linux. Las guías difieren en detalles de versión: si algo falla, revisa el README oficial.

    1. Instala Node.js, de preferencia la versión LTS más nueva. Una guía pide Node 22 o más nuevo; otra dice que basta con 18.
    2. Instala OmniRoute:
      npm install -g omniroute
    3. Arráncalo. Se abre el panel en http://localhost:20128:
      omniroute
    4. Si algo no arranca, revisa puertos y dependencias. El asistente te guía la primera vez:
      omniroute doctor
omniroute setup
    5. En el panel, entra a Providers y conecta uno. Empieza por los de llave gratis (tabla de abajo).
    6. Crea una llave de OmniRoute en el panel (aparece como Endpoints o API Keys, según la versión).

    Conectarlo con Claude Code

    La forma rápida: con OmniRoute abierto, corre este comando. Pone la conexión solo para esa sesión y abre Claude Code.

    omniroute launch

    La forma manual: dos variables de entorno y luego abres Claude Code. La dirección va sin /v1.

    
        
    Deja OmniRoute abierto mientras uses Claude Code. Si lo cierras, deja de contestar.

    Cómo se trabaja con OmniRoute
    
      
    La idea: el trabajo grande lo hacen los modelos gratis de OmniRoute. Cuando algo queda casi bien y solo falta corregir un detalle, cambias de cerebro un momento, pides solo esa corrección y regresas.
    

      
    
        
    Paso 1
    Trabaja con OmniRoute
    Construye, prueba y repite con tu combo pensar. Aquí se gasta la cuota gratis.
    
        
    Paso 2
    Corre las pruebas
    Si pasan, sigue. Si fallan una o dos veces, deja que el mismo combo lo intente de nuevo.
    
        
    Paso 3
    Cambia de cerebro
    Si falla de nuevo o falta un detalle chico, usa un modelo más fuerte. Pídele solo esa corrección.
    
        
    Paso 4
    Regresa a OmniRoute
    Corregido el detalle, vuelves al combo gratis y sigues con lo siguiente.
    
      
    

      
    
        
    Por qué así
    
        
      
          
    • Lo grande es mucho texto, y ahí se acaba la cuota. Eso se queda en lo gratis.
      • 
          
    • Una corrección mínima es poco texto, así que gastarla en un modelo fuerte cuesta poco y casi siempre sale a la primera.
      • 
          
    • Un modelo gratis se atora en lo difícil: repite el mismo error. Cambiar de cerebro rompe ese ciclo.
      • 
        
    
      
    

      
    
        
    Combos con 6 cuentas
    
        
    Un combo es una lista de modelos en orden. Si el primero se agota o falla, OmniRoute pasa al siguiente. Lo creas en el panel, en la sección de combos (el nombre exacto cambia según la versión).
    
        
    
          
    EstrategiaCómo funcionaÚsala para
    
          
            
    PrioridadSiempre prueba en el orden de la lista. El primero hace todo hasta que falla.Programar: mejor calidad primero.
    
            
    Round-robinReparte entre cuentas equivalentes. La guía dice que por defecto da 3 llamadas a cada cuenta antes de pasar a la siguiente.Repartir carga entre cuentas iguales.
    
            
    Fill-firstGasta una cuenta por completo antes de pasar a la otra.Aprovechar una cuenta hasta el final.
    
          
    

        
    Las 6 cuentas: una por proveedor
    
        
    La forma más limpia son los seis de la pestaña OmniRoute: Groq, NVIDIA NIM, Google AI Studio, Mistral, LongCat y OpenRouter, una cuenta de cada uno. Así los combos se reparten entre proveedores distintos y cada uno aporta su cuota.
    
        
    Ojo con las cuentas repetidas: abrir varias cuentas del mismo servicio gratis para saltarte su límite puede ir contra sus términos y te pueden suspender todas. Usa tus propias cuentas, una por proveedor, y lee los términos de cada uno.

    Cuidados
    
      
    Seis reglas que te ahorran problemas.
    
      
    
        
    Plugins con cuidado
    Pueden ejecutar comandos en tu computadora. Instala solo los conocidos y revisa en GitHub quién los hizo y cuándo se actualizaron.
    
        
    Llaves fuera del chat
    Nunca pegues llaves ni contraseñas en el chat. Guárdalas como variables de entorno o en un archivo .env que no subas a GitHub.
    
        
    Cuentas aparte
    Algunos servicios prohíben usar su cuenta por programas intermedios y pueden suspenderla. No uses tu cuenta principal de Google o GitHub para probar eso.
    
        
    Trading: demo primero
    No le des a ninguna herramienta llaves con permiso de retiro. No pongas dinero real hasta entender qué hace cada orden.
    
        
    Una cuenta por proveedor
    Abrir varias cuentas del mismo servicio gratis para saltarte su límite puede ir contra sus términos y suspender todas. Usa una cuenta tuya por proveedor.
    
        
    Lo gratis tiene límite
    Para trabajo serio todos los días, un plan de pago es más estable que juntar cuentas gratis.
